# GuardBot Docs Website

> Официальный сайт документации GuardBot: **https://docs.guardbot.tech/**

Красивый статический сайт с документацией по Telegram-боту GuardBot: настройка, команды, модули защиты, FAQ и двуязычный интерфейс (EN/RU).

## ✨ Что это за проект

Этот репозиторий содержит фронтенд документационного сайта GuardBot.
Сайт собран на чистых веб-технологиях без сборщиков и фреймворков:

- **HTML** (`docs/index.html`)
- **CSS** (`docs/style.css`)
- **Vanilla JavaScript** (встроен в `index.html`)

## 📚 Что есть на сайте

- Введение и требования к установке
- Пошаговый Setup Guide
- Полный список команд
- Deep Dive по ключевым настройкам
- Раздел модулей безопасности
- Почему GuardBot (trust/security)
- FAQ

## 🌐 Языки

Сайт поддерживает 2 языка интерфейса:

- English
- Русский

Переключение языка выполняется на стороне клиента через JavaScript.

## 🚀 Локальный запуск

Так как это статический сайт, достаточно открыть `index.html` в браузере.

Рекомендуемый вариант (через локальный HTTP-сервер):

1. Перейдите в директорию проекта.
2. Запустите любой статический сервер для папки `docs`.
3. Откройте сайт в браузере.

Примеры:

- Python: `python -m http.server 8000` (из папки `docs`)
- Node.js: `npx serve docs`

## 🛠 Редактирование контента
