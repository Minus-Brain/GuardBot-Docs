## English

GuardBot is an automated system for Telegram group moderation designed to keep your community safe and clean.

### Key Features

*   **Smart Captcha:** Four verification methods (Button, Math, Image, and Custom) to prevent automated accounts from joining.
*   **Anti-Raid System:** Real-time monitoring of join rates with automatic lockdown protocol.
*   **Content Filtering:** Advanced text analysis to block spam, floods, duplicates, and excessive emojis/uppercase characters.
*   **Link Protection:** Automatically removes external links and Telegram invites, with a customizable whitelist.
*   **Media Restrictions:** Set limits on file sizes and restrict specific media types.
*   **Administrative Tools:** Comprehensive commands for status reports, logs, backups, and scheduled tasks.

### Quick Start

1.  Add **GuardBot** to your Telegram group.
2.  Grant **Administrator** rights (Delete messages and Ban users).
3.  Use `/on` to activate protection.
4.  Configure settings with `/settings` or `/captcha`.

## Русский

GuardBot — это автоматизированная система модерации групп в Telegram, предназначенная для защиты вашего сообщества от спама и атак.

### Ключевые возможности

*   **Умная капча:** Четыре метода верификации (кнопка, математика, изображение и кастомный вопрос) для предотвращения вступления ботов.
*   **Анти-рейд система:** Мониторинг скорости вступлений в реальном времени с автоматическим протоколом блокировки.
*   **Фильтрация контента:** Продвинутый анализ текста для блокировки спама, флуда, дубликатов и чрезмерного использования эмодзи/заглавных букв.
*   **Защита от ссылок:** Автоматическое удаление внешних ссылок и инвайтов Telegram с настраиваемым белым списком.
*   **Медиа-ограничения:** Установка лимитов на размер файлов и запрет определенных типов медиа.
*   **Инструменты администрирования:** Полный набор команд для отчетов, логов, бэкапов и запланированных задач.

### Быстрый старт

1.  Добавьте **GuardBot** в вашу группу Telegram.
2.  Выдайте права **Администратора** (Удаление сообщений и Блокировка пользователей).
3.  Используйте команду `/on` для активации защиты.
4.  Настройте параметры с помощью `/settings` или `/captcha`.
